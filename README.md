# tping / tping3 / tping2

> Набор инструментов для **нагрузочного тестирования собственных серверов**.

| Инструмент | Уровень | Назначение |
|------------|---------|------------|
| **tping**  | L3/L4   | UDP, IPSO, ICMP |
| **tping3** | L7      | HTTP/HTTPS, Slowloris, RUDY, HTTP/2 |

> ⚠️ **Важно:** инструменты предназначены **только для тестирования собственных серверов** или систем, на которые у вас есть **письменное разрешение владельца**.

## Что такое нагрузочное тестирование

**Нагрузочное тестирование** (load testing) — это проверка того, как сервер ведёт себя под высокой нагрузкой. Цель — понять пределы его устойчивости:

- сколько запросов он держит,
- при каком уровне начинает отвечать медленно,
- когда возвращает **HTTP 503 Service Unavailable** или перестаёт отвечать.

Это **не атака**, а **инженерный тест**. Используется администраторами и пентестерами, чтобы:

- убедиться, что сервер выдержит наплыв пользователей,
- проверить работу anti-DDoS, WAF, CDN, rate-limiter,
- оценить, нужен ли апгрейд железа или канала.

## Возможности

### tping (сетевой уровень)

| Возможность | Описание |
|-------------|----------|
| UDP-пакеты | До 65507 байт |
| IPSO | Собственный формат (флаг `-ipso`) |
| ICMP | Echo-запросы (флаг `-icmp`) |
| Многопоточность | До 256 потоков |
| Автостоп | По времени (`-d SEC`) и количеству (`-c N`) |
| Статистика | Байты, пакеты, потери, MB/s, pps |
| Режимы | `-dos` / `-ddos` |
| Таблица | `-table` |

### tping3 (прикладной уровень)

| Возможность | Описание |
|-------------|----------|
| GET-флуд | HTTP GET-запросы |
| POST-флуд | HTTP POST-запросы |
| HTTP/2 | Мультиплексирование |
| Slowloris | Медленное занятие TCP |
| RUDY | Slow POST |
| Mix | Всё вместе |
| Многопоточность | До 512 потоков |
| Статистика | RPS и коды 200/429/503/timeout |
| UA-файл | Загрузка списка User-Agent |
| Режимы | `-dos` / `-ddos` |
| Прокси | Файл или GitHub |

## Режимы tping

| Режим | Флаг | Что делает |
|-------|------|-----------|
| UDP | (по умолч.) | Отправляет UDP-пакеты |
| IPSO | `-ipso` | UDP + собственный заголовок IPSO |
| ICMP | `-icmp` | Echo-запросы (нужен root) |
| DoS | `-dos` | Отправка с локального IP |
| DDoS | `-ddos` | Отправка через прокси |

---

## Режимы tping3

| Режим | Флаг | Что делает |
|-------|------|-----------|
| GET | `-mode get` | HTTP GET-флуд |
| POST | `-mode post` | HTTP POST-флуд |
| HTTP/2 | `-mode http2` | HTTP/2-мультиплексирование |
| Slowloris | `-mode slowloris` | Медленные соединения |
| RUDY | `-mode rudy` | Slow POST |
| Mix | `-mode mix` | Всё вместе |
| DoS | `-dos` | Отправка с локального IP |
| DDoS | `-ddos` | Отправка через прокси |

## Установка на Linux

### Ubuntu / Debian / Kali

```bash
sudo apt update
sudo apt install -y g++ libcurl4-openssl-dev libssl-dev libcap-dev curl
git clone https://github.com/persik-os/tping.git
cd tping
make
sudo cp tping tping3 /usr/local/bin/
sudo setcap cap_net_raw+ep /usr/local/bin/tping
```

# Флаги Tping
Флаг Описание
-dos отправка с локального IP (по умолчанию)
-ddos отправка через прокси
-ipso формат IPSO поверх UDP
-icmp ICMP-режим (нужен root)
-l бесконечная отправка
-t <N> число потоков (1..256)
-d <SEC> длительность в секундах
-c <N> пакетов на поток
-p <PORT> порт (по умолчанию 80)
-table таблица размеров
-help справка

# Флаги Tping3
Флаг Описание
-dos отправка с локального IP (по умолчанию)
-ddos отправка через прокси

-mode режим работы (по умолчанию get)
-t <N> число потоков (1..512)
-d <SEC> длительность в секундах
-ua <FILE> файл User-Agent
