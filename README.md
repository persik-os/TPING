# tping / tping3

A network load testing tool by [@persik-os](https://github.com/persik-os).

Набор утилит для **нагрузочного тестирования собственных серверов**:
- **tping** — тестирование сетевого уровня (UDP / IPSO / ICMP).
- **tping3** — тестирование прикладного уровня (HTTP / HTTPS, Slowloris, RUDY, HTTP/2).

Инструменты предназначены **только для тестирования собственных серверов** или систем, на которые у вас есть **письменное разрешение владельца**.

## Возможности

### tping (сетевой уровень)

- Отправка UDP-пакетов произвольного размера (до 65507 байт).
- Собственный формат пакета **IPSO** (флаг `-ipso`).
- **ICMP**-режим (флаг `-icmp`).
- Многопоточность до 256 потоков.
- Ограничение по времени (`-d SEC`) и количеству пакетов (`-c N`).
- Живая статистика: байты, пакеты, потери, MB/s, pps.
- Встроенная таблица единиц и максимальных размеров пакетов (`-table`).

### tping3 (прикладной уровень)

- HTTP GET-флуд.
- HTTP POST-флуд.
- HTTP/2-мультиплексирование.
- **Slowloris** — медленное занятие TCP-соединений.
- **RUDY** — медленная отправка тела POST.
- Смешанный режим (всё вместе).
- Многопоточность до 512 потоков.
- Живая статистика: RPS и коды ответов (200 / 429 / 503 / timeout).
- Загрузка списка User-Agent из файла.

## Установка

### Требования

- Компилятор C++17 (`g++` 9+).
- Linux (Kali, Ubuntu, Debian, Arch и т.д.).
- **libcurl** и **OpenSSL** для `tping3`.
- Для ICMP-режима `tping` и raw-сокетов — root или capability `cap_net_raw`.

### Установка зависимостей (Debian/Ubuntu)

```bash
sudo apt update
sudo apt install -y g++ libcurl4-openssl-dev libssl-dev libcap-dev
```bash
git clone https://github.com/persik-os/tping.git
cd tping
g++ -O2 -pthread -std=c++17 -o tping tping.cpp
