# tping

A network load testing tool by [@persik-os](https://github.com/persik-os).
**tping** — утилита для нагрузочного тестирования сетевых серверов на C++.
Работает поверх **UDP** с опциональной поддержкой собственного формата пакетов **IPSO**, а также поддерживает **ICMP**-режим.

Инструмент предназначен **только для тестирования собственных серверов** или систем, на которые у вас есть письменное разрешение владельца.

---

## Возможности

- Отправка UDP-пакетов произвольного размера (до 65507 байт).
- Собственный формат пакета **IPSO** (флаг `-ipso`).
- **ICMP**-режим (флаг `-icmp`) для проверки сетевой доступности.
- Многопоточность до 256 потоков (`-t N`).
- Ограничение по времени (`-d SEC`) и по количеству пакетов (`-c N`).
- Живая статистика: байты, пакеты, потери, MB/s, pps.
- Итоговый отчёт с подсчётом потерь.
- Встроенная таблица единиц и максимальных размеров пакетов (`-table`).

## Установка

### Требования

- Компилятор C++17 (`g++` 9+).
- Linux (Kali, Ubuntu, Debian, Arch и т.д.).
- Для ICMP-режима и raw-сокетов нужен root.

### Сборка

```bash
git clone https://github.com/persik-os/tping.git
cd tping
g++ -O2 -pthread -std=c++17 -o tping tping.cpp
